# Convenio de transferencia de datos personales

## ¿Qué es?

Es el acuerdo que firman dos empresas cuando una (el **responsable transferente**, quien entrega) comparte datos personales con otra (el **responsable receptor**, quien recibe) para que esta los use **para sus propios fines**. A esto la ley le llama **transferencia**. El convenio asegura que quien recibe asuma las mismas obligaciones que quien entrega, respete el aviso de privacidad con el que se obtuvieron los datos y solo los use para las finalidades permitidas. Sirve para transferencias dentro de México y hacia otros países.

## ¿Cuándo usarla?

- Compartes datos de clientes con un socio comercial para ofertas conjuntas o un programa de lealtad.
- Compartes datos entre empresas de un mismo grupo (por ejemplo, la empresa mexicana y su matriz en otro país).
- Vendes o transmites una cartera de clientes, o haces una fusión o adquisición donde pasan datos.
- Compartes datos con un revendedor o distribuidor que atenderá a los clientes por su cuenta.
- Recibes datos de otra empresa para usarlos en tus propios servicios.

## ¿Cuándo NO usarla?

- **El que recibe solo trata los datos por tu cuenta** (por ejemplo, un proveedor de nube, correo o nómina). Eso es una **remisión** a un **encargado**. Usa la plantilla `contrato-de-encargado-de-datos-personales`.
- **Los datos están disociados o anonimizados** de forma que ya no identifican a nadie: no son datos personales. Basta con un contrato de licencia de datos con cláusula de no reidentificación.
- **Entregas datos a una autoridad por orden legal:** no necesitas convenio, pero documenta el requerimiento.
- **Alguna de las partes es una dependencia de gobierno:** aplica otra ley de datos personales (sector público).

## Puntos clave

- **Mismas obligaciones:** el receptor asume las mismas obligaciones que el transferente frente a los titulares.
- **Respeto al aviso de privacidad:** el receptor solo puede usar los datos para las finalidades que se informaron en el aviso de privacidad bajo el cual se obtuvieron. Se adjunta como anexo.
- **¿Cuándo se necesita consentimiento del titular?** La regla general es que toda transferencia necesita consentimiento. La ley prevé excepciones (por ejemplo, cuando la transferencia la exige una ley, es entre empresas del mismo grupo con las mismas políticas, o es necesaria para un contrato en interés del titular). El convenio pide señalar qué base aplica y quién obtiene el consentimiento.
- **Transferencias internacionales:** el receptor extranjero se obliga a proteger los datos como lo exige la ley mexicana.
- **Transferencias posteriores:** el receptor no puede volver a transferir los datos sin cumplir las mismas reglas.
- **Derechos ARCO:** las partes se coordinan para atender solicitudes de los titulares.
- **Vulneraciones de seguridad:** cada parte responde por las que ocurran en sus sistemas y se avisan entre sí.

## Antes de firmar, revisa

- [ ] Confirmaste que es una **transferencia** (el receptor usa los datos para sus propios fines) y no una remisión.
- [ ] El aviso de privacidad del transferente **menciona esta transferencia** (destinatario o tipo de destinatario y finalidad).
- [ ] Identificaste si se necesita **consentimiento** del titular o si aplica una excepción de la ley, y tienes evidencia de ello.
- [ ] Si se necesita consentimiento, sabes quién lo obtuvo, cómo y cuándo, y lo puedes demostrar.
- [ ] Las finalidades del receptor son compatibles con las del aviso de privacidad original.
- [ ] Respetaste a los titulares que se negaron a la transferencia o a finalidades secundarias (se excluyen de los datos que se entregan).
- [ ] Si el receptor está fuera de México, el país está indicado y el receptor acepta proteger los datos como exige la ley mexicana.
- [ ] Solo se transfieren los datos necesarios (principio de proporcionalidad).
- [ ] El receptor tiene su propio aviso de privacidad y lo comunicará a los titulares.
- [ ] Los representantes que firman tienen poder suficiente.
